# Testing

All tests use synthetic fixtures generated by `src/geodesic/synthetic/`:
workbooks, PDF and XML documents, provider responses and search files. No
real paper is downloaded as a fixture and no project evidence is in the test
suite. Fixture provider responses carry the synthetic tag and are never
presented as live results.

The numbers below are observations from the runs named. They are not
targets, and timings depend on the machine.

## Commands

Run from the repository root, with the environment from `README.md`.

| Purpose | Command | Network |
|---|---|---|
| Standard tests | `python -m pytest tests` | none |
| Network tests | `python -m pytest tests -m network` | Europe PMC, Crossref |
| Scale smoke test | `python -m pytest tests -m scale -s` | none |
| Offline demonstration | `geodesic demo` | none |
| Bounded live search check | `geodesic live-smoke` | Europe PMC, Crossref |

The standard run deselects the `network` and `scale` tests (set in
`pyproject.toml`).

Separation of synthetic and real data (refusal of untagged or contradicting
inputs, of live retrieval in synthetic projects, of simulated reviewers in
real projects, and of real projects or exports inside source control) is
tested in the file of each feature it applies to.

What these tests do not cover: download buttons in the dashboard are not
exercised by `AppTest`; the dashboard was not tested in a browser by an
automated test; installation with plain `pip` was not exercised (the
environment was built with `uv`).

## Live verification

Live checks send one small query taken from configuration
(`search.smoke_query`, 6 records in pages of 3). They check
retrieval mechanics, counts and response schema. Record content is not
summarised or analysed, and the temporary project is deleted afterwards.

Observed 2026-11-10 UTC (03:46; first verified the same day at about 02:01):

    geodesic live-smoke                  11 passed, 0 failed, 0 unverified
    python -m pytest tests -m network    5 passed, 336 deselected in 6.97s

| Verified live on 2026-11-10 UTC | Check |
|---|---|
| Europe PMC search | Response shape; `hitCount`; cursor pagination over 2 pages; retrieval limit and `truncated` status; stored raw responses re-read with matching SHA-256; `id` and `source` on every record |
| Europe PMC filters | `PUB_YEAR` range and `OPEN_ACCESS:y` honoured by the returned records; filtered total not above the unfiltered total |
| Crossref | Lookup of one work by DOI: status, returned DOI, documented shape |
| Europe PMC full text | One open-access `fullTextXML` retrieved by PMCID, stored with its hash, parsed into addressable units |

Not verified live:

- Crossref bibliographic matching (`query.bibliographic`). Tested against
  fixtures only.
- The Crossref Plus token. No token was available; only its redaction is
  tested.
- Provider behaviour on a real rate limit (HTTP 429 with `Retry-After`).
  Tested with a local stub transport only.
- Any search larger than the smoke query.

Provider interfaces change. A pass on this date says nothing about a later
date; run `geodesic live-smoke` before relying on a live search.

## Scale smoke test

    GEODESIC_SCALE_DIR=/some/empty/dir python -m pytest tests -m scale -s

`GEODESIC_SCALE_PAPERS` (default 10000) and `GEODESIC_SCALE_FINDINGS`
(default 100000) set the size. The test builds a synthetic project through
the ordinary application functions, prints the time of each step and writes
`scale_report.json`. It asserts that counts are complete and that every
finding keeps its provenance. It sets no time limits.

Observed 2026-11-09 (local) at the default, full size:

    3 passed, 338 deselected in 141.34s (0:02:21)

`examples/scale_test/SYNTHETIC_scale_report.json`.
